# Aspen Snowmass — Exploration C

Progressive Discovery is a separate working navigation exploration: category → options → useful context. Desktop retains earlier selections in adjacent panels; tablet/mobile presents one level at a time. A persistent utility layer provides Trail Maps, Weather, Mountain Cameras, Lift Status and Parking.
